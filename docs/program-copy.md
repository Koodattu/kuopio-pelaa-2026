# Ohjelman julkiset esittelytekstit

## Ohjelman nimi

**Tekoäly tuli – nyt kaikki on ohi... vai onko?**

- Pituus: 45 / 60 merkkiä

## Nettisivujen esittely

> Onko kaikki nyt ohi, loppuuko pelinkehitys vai pääseekö kuka tahansa tekemään pelejä? Tekoäly kirjoittaa, piirtää ja koodaa, mutta syntyykö sillä peli, jota joku haluaa pelata? Esitys seuraa tekoälyä tekijän työpöydältä pelaajan ruudulle. Kuka valitsee, kuka kertoo ja kuka vastaa lopputuloksesta? Työpajassa pääset itse kokeilemaan: puhelimella tai läppärillä rakennat tekoälyn avulla pienen peliprototyypin suoraan selaimessa. Ohjelmointiosaamista ei vaadita, tarvitset vain idean ja kokeilunhalua!

- Pituus: 500 / 500 merkkiä
- Kopioi lomakkeelle yhtenä kappaleena ilman ylimääräisiä rivinvaihtoja.
