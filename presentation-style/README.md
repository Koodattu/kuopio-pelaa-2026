# Presentation style guide

A reusable description of the style of *Tekoäly tuli – nyt kaikki on ohi...
vai onko?* (Kuopio Pelaa 2026, `pptx/KuopioPelaaEsitys.pptx`), written so the
same style can be applied to a talk on any other topic.

## The style in one paragraph

A **scrapbook-framed, journalistic explainer**. The frame slides (title,
agenda, bio, takeaways, contacts) are hand-made collage: corkboard, cardboard,
ransom-note title letters, pinned pastel sticky notes and a cut-out photo of
the speaker. The body is clean warm-paper explainer slides that build an
argument out of data, real news cases and pop-culture memes. Every slide asks
or claims one thing, backs it with visible evidence and a source, and ends on
a one-line punchline or a question to the room. The tone is curious and
sceptical, never preachy: the talk gives the audience criteria to judge with,
not a verdict, and then hands them the tool in a hands-on workshop.

## Quick start for a new topic

1. Write the provocative title with built-in doubt (see
   [03](03-narrative-and-tone.md#the-title)).
2. Fill in the arc in [04-deck-template.md](04-deck-template.md) with
   placeholders only — one line per beat.
3. For each beat, pick a slide type from
   [02-slide-patterns.md](02-slide-patterns.md).
4. Build the frame slides first (title, agenda corkboard, closing corkboard) so
   the deck has its identity before the content exists.
5. Run [05-checklist.md](05-checklist.md) before the first rehearsal.
