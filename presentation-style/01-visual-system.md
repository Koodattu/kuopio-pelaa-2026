# 01 · Visual system

Values below are measured from `pptx/KuopioPelaaEsitys.pptx` (16:9,
13.333 × 7.5 in).

## Two surfaces

The deck alternates between two clearly different surfaces. Never mix them on
one slide.

| | **Frame surface** (scrapbook) | **Content surface** (paper explainer) |
|---|---|---|
| Used for | Title, agenda, bio, section returns, takeaways, closing/contacts, audience prompts | Everything that argues: data, quotes, cases, comparisons |
| Background | Corkboard or corrugated cardboard texture | Warm off-white paper texture |
| Type | Ransom-note cut-out letters for the title; playful display font on notes | Heavy black title top-left, grey subtitle, plain body |
| Objects | Pastel sticky notes held by push pins, taped paper labels, cut-out speaker photo, a mascot | Charts, quote cards, screenshots, sticky-note boxes used sparingly |
| Feel | Hand-made, personal, playful | Calm, readable, evidence-first |

A third, occasional surface: **full-bleed image** (game key art, a meme, a
video). It has no title, only a small credit such as `Kuva: Studio` at bottom
left.

## Colour

### Base

| Role | Hex | Notes |
|---|---|---|
| Paper background | `#F1ECE1` | Warm off-white; use a subtle paper texture image, not a flat fill. |
| Paper, darker edge | `#DFDCD3` / `#D5CEB9` | Card backgrounds, dividers. |
| Primary text | `#20231F` / `#000000` | Near-black for titles and body. |
| Secondary text | `#66665C` | Subtitles, source lines, axis labels. |

### Accents

| Role | Hex | Use |
|---|---|---|
| Data / emphasis blue | `#0070C0` | Big numbers, highlighted words in quotes, default chart series. |
| Bright blue | `#00B0F0` | Sticky notes, timeline dots. |
| Positive | `#00B050`, `#78B727`, `#92D050` | "Myönteinen", good outcome. |
| Mixed / neutral | `#FFC000`, `#F4A505` | "Sekalainen", "Neutraali", warnings. |
| Negative | Deep red / burnt orange, e.g. `#B64E30` | "Kielteinen", bad outcome. |
| Salmon note | `#FF8B8B` | The key question note on the agenda board. |
| Teal | `#74A99B` | Display words like **TEKOÄLY**. |

### Sticky-note pastels

Light blue, pink/lilac, green, peach and yellow. Rules:

- One idea per note.
- Colour carries **no meaning** on frame slides; it is decoration. Do not let
  pastel colours encode data.
- On content slides, use at most 2–3 notes, and only for a framework or a
  take-away pair.

## Typography

| Role | Font | Size | Notes |
|---|---|---|---|
| Content slide title | **Arial Black** | 32 pt | Top-left, sentence case, often a question. |
| Subtitle | Aptos / Segoe UI | 18 pt, grey | One line, sets up or twists the title. |
| Body | Aptos / Segoe UI | 18–24 pt | Short lines; no bullet walls. |
| Big number | Aptos / Segoe UI bold, blue | 60–72 pt | With a short label beside it. |
| Bottom punchline | Arial Black / bold body | 18–20 pt | One sentence, bottom of slide. |
| Source line | Aptos | 10–12 pt, grey | `Lähde:` + underlined linked names, bottom-left. |
| Playful display | **Bungee** | varies | Audience prompts ("Saa kysyä!", "kysytään yleisöltä"), sticky notes. **Embed it** or install it on the presenting machine. |
| Title words | Images | — | Ransom-note words are separate cut-out PNGs, not a font. |

## Layout

- **Title block**: top-left, title then subtitle, same position on every
  content slide so the eye always knows where to start.
- **Content zone**: the middle ~70 %. Usually one of: chart, two columns, three
  boxes, a quote grid, or a timeline.
- **Punchline zone**: a single bold line near the bottom.
- **Source zone**: bottom-left, small, always present when there is a claim.
- Generous empty paper. If the slide feels full, it is two slides.

## Imagery

- **Speaker cut-out**: a photo with the background removed and a white
  sticker-style outline. Appears on title, agenda and closing.
- **Mascot**: a cardboard robot with a CRT head and many arms holding tools of
  the topic (paintbrush, pen, microphone, controller). Swap the props for a new
  topic.
- **Cut-out title words**: each word in mixed ransom-note letters as its own
  PNG, so they can be animated and reused (the original set lives in `pptx/`).
- **Evidence screenshots**: real headlines, tweets, statements. Crop tight, keep
  the outlet name visible.
- **Full-bleed key art** for case studies, then reused faded behind the text
  slides of the same case.
- **Memes and reaction GIFs**: full-slide, no title. Pop culture the audience
  recognises (Simpsons, Terminator, Back to the Future, Rick & Morty, classic
  meme formats translated into Finnish).

### If the illustrations are AI-generated

Say so on a slide (for example on the bio or closing slide:
*"Tämän esityksen kuvituksessa on käytetty tekoälyä."*). The style leans on
holding others to account; it must hold itself to the same standard.
